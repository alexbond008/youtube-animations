1. Read the handout and the data in data/given/.
2. EDA in Python: plot the step responses; measure
   rise time, overshoot, settling time.
3. Fit a 1st/2nd-order model. State assumptions.
4. Answer every supervisor pre-lab question,
   with working and units.
Write prelab/answers.md. Flag anything uncertain.
